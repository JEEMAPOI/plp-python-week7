# Week 7 Assignment: My Notes & The Report Builder

## Files

- `my_notes.py` - writes, appends, reads and counts lines in a notes file.
- `my_notes.txt` - the notes file created by `my_notes.py`.
- `report_builder.py` - reads `hubs.csv` and writes a learner report.
- `hubs.csv` - the learner data (name, hub, score).
- `report.txt` - the report created by `report_builder.py`.

## Question

What would happen if you changed "a" to "w" in Question 1?

The file would be erased and rewritten, so the first three notes would be lost. Only "I added this later" would remain, and the line count would be 1 instead of 4.
